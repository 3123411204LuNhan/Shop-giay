Hướng dẫn control code ShopGiay C#

Bản ASP.NET Core dùng MySQL, giữ giao diện React và hợp đồng API của Shop-giay-main. Tài liệu này giúp bạn xác định đúng file để sửa, giải thích hướng đối tượng và lần theo một yêu cầu từ nút bấm đến database.

Chạy và cấu hình

  1. Mở ShopGiay.sln bằng Visual Studio 2026; chọn ShopGiay.Web làm Startup Project.
  2. Cài workload ASP.NET and web development và SDK .NET 10. Microsoft xác nhận .NET 10 dùng Visual Studio 2026 từ 18.0.
  3. Chạy configure-mysql.cmd hoặc dotnet run --project src/ShopGiay.Web -- --db-config để nhập mật khẩu ẩn và kiểm tra trước khi lưu. Chạy --db-check để kiểm tra database. Nếu cấu hình thủ công: copy src/ShopGiay.Web/appsettings.Local.example.json thành appsettings.Local.json, điền mật khẩu và database MySQL.
  4. Database cũ: dùng đúng tên hiện có, không seed. Database mới: chạy setup và seed theo README.txt.
  5. F5 hoặc Ctrl+F5; mở http://localhost:5173. wwwroot đã có giao diện build sẵn.

Cấu hình cũ DB_HOST/PORT/NAME/USER/PASSWORD được gộp vào ConnectionStrings:ShopGiay. Hạn giữ hàng và trả hàng chuyển vào Store; cấu hình email vào Mail. SMTP dùng STARTTLS cổng 587. Khi chưa cấu hình SMTP, đọc mã tại src/ShopGiay.Web/.local/mail.

dotnet run --project src/ShopGiay.Web -- --db-setup
dotnet run --project src/ShopGiay.Web -- --db-seed
dotnet run --project src/ShopGiay.Web

# Nếu schema hiện có thiếu cột quy trình, sao lưu rồi chạy:
dotnet run --project src/ShopGiay.Web -- --db-migrate

Seed có khách khach@sole.vn, quản lý shop@sole.vn, kỹ thuật admin@sole.vn; mật khẩu demo SoleDemo@123. Các khu vực đăng nhập: /, /manager, /admin. Dữ liệu đang dùng được giữ bằng cách kết nối cùng database; không cần chuyển tên bảng hoặc import lại đơn.

Cấu trúc và hướng đối tượng

ShopGiay.sln
├─ src/ShopGiay.Web
│  ├─ Program.cs                điểm vào, DI, middleware, chạy nền
│  ├─ Controllers/              URL, HTTP method và chuyển dữ liệu tới Service
│  ├─ Services/                 nghiệp vụ và ranh giới transaction
│  ├─ Repositories/I*.cs        hợp đồng truy cập dữ liệu
│  ├─ Repositories/*Repository.cs  SQL có tham số, đọc/ghi MySQL
│  ├─ Domain/                   Account, InventoryBalance, OrderWorkflow
│  ├─ Infrastructure/           Database, SessionContext, PasswordHasher, cấu hình
│  └─ wwwroot/                  HTML/CSS/JS đã build để ASP.NET phục vụ
├─ frontend/src                 React gốc để chỉnh sửa giao diện
├─ database/schema.sql          37 bảng MySQL của bản gốc
├─ tests/ShopGiay.Tests          kiểm tra quy tắc C# và hash mật khẩu cũ
└─ tests/Regression             HTTP → C# → MySQL để kiểm tra tương thích
React → Controller → Service → interface Repository → Repository → Database → MySQL

Đóng gói: InventoryBalance.Apply bảo vệ 0 ≤ phân bổ ≤ tồn; Account bảo vệ vai trò/xóa; OrderWorkflow giới hạn chuyển trạng thái. Trừu tượng và đa hình: Service nhận IAuthRepository… hoặc IPasswordHasher, Program đăng ký lớp thực thi qua DI. Kế thừa: các Controller kế thừa ShopController rồi ControllerBase; worker kế thừa BackgroundService.

Row là cấu trúc dữ liệu cho JSON và SQL projection để giữ nguyên tên trường React. Nó cung cấp S (chuỗi), N (decimal), L (số nguyên), B (bool), D (ngày UTC), Rows (dòng hàng). Quy tắc nghiệp vụ nằm trong Service/Domain. DbSession mang một connection và transaction tới mọi Repository trong một nghiệp vụ.

Muốn đổi giao diện: sửa frontend/src rồi build. Muốn đổi quy tắc nghiệp vụ: sửa Service/Domain. Muốn đổi câu SQL: sửa Repository. Muốn thêm chức năng: thêm method vào interface, implementation, Service rồi route Controller. Mật khẩu mới PBKDF2; mật khẩu scrypt cũ vẫn được xác minh.

Lần theo thao tác đặt hàng

  1. frontend/src/operations.jsx → CheckoutReview nhận biểu mẫu và gọi api('/checkout/quote',v).
  2. frontend/src/main.jsx → api thêm X-Sole-Request, khu vực, tài khoản hiện tại rồi gửi HTTP tới /api.
  3. ApiSecurityMiddleware kiểm tra Origin/header, phiên và vai trò; không nhận ID chủ giỏ từ form.
  4. CheckoutController.Quote chuyển JSON sang Row rồi gọi CheckoutService.Quote.
  5. Snapshot lấy giỏ, kiểm trạng thái hàng, khóa TonKho, kiểm ưu đãi, tính phí và fingerprint.
  6. Người dùng xác nhận; React gửi /orders với requestId và fingerprint. PlaceOrder khóa khách, kiểm requestId đã tồn tại và tính lại snapshot.
  7. Repository ghi DonHang, ChiTietDonHang; Operations.StockLog giữ kho, ghi sổ; tạo ThanhToan chờ xác nhận, lưu ưu đãi và xóa giỏ.
  8. Database.Transaction COMMIT nếu toàn bộ thành công, ROLLBACK khi có lỗi. Controller trả ID/tổng tiền để React hiển thị.

Đặt breakpoint: F9 tại đầu CheckoutController.PlaceOrder, đầu CheckoutService.PlaceOrder, Operations.StockLog và Database.Query. F10 đi qua câu lệnh, F11 đi vào hàm, Shift+F11 quay ra. Mở Locals/Watch để xem b, session.UserId, s.Items, sql, values. F12 mở định nghĩa; Shift+F12 tìm chỗ gọi; Ctrl+G nhảy tới số dòng trong bảng dưới.

Đặt tên API: Controller nhận URL có {id}; Service dùng ID ấy để xác định đối tượng, còn ID chủ sở hữu lấy từ session. Tham số c là giao dịch đang mở. Các lệnh await chờ bước hiện tại hoàn thành rồi mới chạy bước kế tiếp.

Đọc code từng dòng

Mỗi dòng có số để nhảy bằng Ctrl+G trong Visual Studio. C# có chú thích // trước hàm và từng câu lệnh. React/CSS có các chỉnh sửa giao diện theo yêu cầu, gồm ẩn mã vận đơn và đồng nhất ảnh sản phẩm. Bộ đọc chỉ hiển thị mã nguồn, không chạy mã này.

Kiểm thử thực tế: xem docs/KET_QUA_KIEM_THU.txt. Đọc README.txt để cấu hình database hiện có hoặc tạo mới. Backend chạy bằng C#; công cụ build React và test HTTP vẫn dùng Node.js.
